# 墨香图书馆座位管理系统

## 项目简介
墨香图书馆座位管理系统，针对高校图书馆占座严重、座位状态不透明、人工管理效率低的现实问题开发。
系统实现图书馆座位可视化展示，支持普通用户在线选座、预约、签到、取消预约；管理员可维护座位状态、代客操作座位。
本原型为**纯前端浏览器应用，数据保存在浏览器内存，刷新页面数据会丢失**
- 场馆规模：1、2楼阅览室，总计48个座位，每层24个座位
- 开馆时间：08:00‑22:00

## 功能模块
### 普通用户
1. 用户登录认证
2. 楼层切换，平面图可视化查看座位状态
3. 按座位状态筛选（全部 / 空闲 / 使用中 / 已预约）
4. 选择日期、时间段预约空闲座位
5. 对自己的预约执行签到、取消预约
6. 查看个人预约记录

### 管理员
1. 管理员账号登录，拥有更高操作权限
2. 强制修改任意座位状态：空闲 / 使用中 / 已预约 / 维护中
3. 代用户进行预约、签到等座位管理操作
4. 查看全部座位平面图与实时统计数据

### 数据统计面板
- 总座位、空闲座位、使用中座位数量统计
- 座位实时占用率展示
- CSS环形图可视化占用比例

## 技术栈
- 前端：HTML5 + CSS3 + 原生JavaScript ES6+
- 无第三方框架、无需编译构建，直接浏览器打开运行
- 数据存储：浏览器内存（运行时变量，刷新丢失）
